# Scroll Reels visual direction

**source**: image

## Character

Scroll Reels is a compact, flat timer label for the Instagram Reels surface. It is easy to read while video content remains the focus. The timer sits at the top right of the Reel, while Instagram owns the navigation buttons.

## Build mandate

Use only black, white, red, and blue in the extension theme. White is the popup and timer surface. Black is the main text and border color. Blue marks primary actions and running state. Red marks stop and completed states. Do not add custom Reel up/down controls, drop shadows, elevations, or offset-card effects.

## Tokens

The source of truth for color tokens is `src/popup.css` and `src/content.css`. Keep future visual changes in those token declarations instead of adding new color literals.
